À propos de MediBook

La plateforme intelligente de gestion de rendez-vous médicaux

🏥

Notre mission

MediBook a été créé pour simplifier la prise de rendez-vous médicaux au Maroc. Notre plateforme connecte patients et médecins de manière efficace, sécurisée et intelligente.

Grâce à notre module d'intelligence artificielle basé sur TF-IDF et la similarité cosinus, nous aidons les patients à trouver la bonne spécialité médicale selon leurs symptômes.

🤖

Notre technologie

Développée avec Django, notre plateforme utilise les dernières technologies web pour offrir une expérience utilisateur optimale.

  • Backend : Django 5.1
  • IA : scikit-learn, TF-IDF
  • Base de données : SQLite / PostgreSQL
  • Déploiement : Docker + Nginx
  • CI/CD : GitHub Actions
